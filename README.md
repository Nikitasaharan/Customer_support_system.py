# Customer Support Ticket System  

## Problem Statement  
The project implements a **Customer Support Ticket System** using Python. It uses **linked lists, stacks, priority queues, circular queues, and polynomial linked lists** to simulate real-world ticket management.  

## Features  
1. **Singly Linked List** – Store tickets dynamically.  
2. **Stack (Undo Operation)** – Revert the last ticket operation.  
3. **Priority Queue** – Process urgent tickets first.  
4. **Circular Queue** – Handle tickets in a round-robin manner.  
5. **Polynomial Linked List** – Represent and compare billing history.  

## Implementation Details  
- **Language**: Python  
- **Data Structures Used**: Linked List, Stack, Priority Queue, Circular Queue  

## Example Workflow  
1. Add new tickets to the system.  
2. Undo the last operation using the stack.  
3. Process urgent tickets first via the priority queue.  
4. Process tickets in a round-robin fashion via the circular queue.  
5. Compare billing history using polynomial linked lists.  

## How to run 
python customer_support_system.py
